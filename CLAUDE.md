# Tempo: правила для работы над проектом

Перед любым изменением интерфейса прочитайте `DESIGN.md`. Коротко: только токены из `src/client/styles/tokens.css`, контраст AA в обеих темах, все состояния компонента, у каждого элемента управления есть имя, тексты без воды. После правок запускайте `npx vitest run`: `design.test.ts` и `A11y.test.tsx` не дадут вернуть сырые цвета и безымянные кнопки.
