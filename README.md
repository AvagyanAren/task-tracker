# Трекер времени

Локальный аналог Toggl Track: таймер, проекты со ставкой за час, записи по дням, отчёт за любой период
с подсчётом часов и денег. Всё хранится у вас на компьютере в одном файле `data/tracker.json`,
наружу ничего не отправляется (сервер слушает только `127.0.0.1`).

## Запуск

Дважды щёлкните **start.bat** — при первом запуске он сам установит зависимости, соберёт интерфейс и откроет
http://localhost:4321. Окно с чёрным фоном закрывать нельзя, пока вы пользуетесь трекером.
Нужен [Node.js LTS](https://nodejs.org).

## Что умеет

- **Таймер**: введите название, выберите проект, «Старт». Новый старт останавливает предыдущий (как в Toggl).
  Идущий таймер хранится в файле, поэтому переживает закрытие окна и перезагрузку компьютера.
- **Записи по дням** с итогом за день; кнопки ▶ продолжить, ✎ править, ✕ удалить.
- **Добавить время вручную**: дата + «сколько времени» (`2:30`, `2.5`, `90m`, `1ч 30м`) — так отмечаются часы
  на задачу за конкретный день.
- **Проекты**: название, ставка за час и валюта. Ставку можно менять — отчёты пересчитаются.
  Проект с записями нельзя удалить, только отправить в архив.
- **Отчёт**: выбор периода (сегодня, неделя, месяц, год, всё время или свои даты), фильтр по проекту.
  Итого часов и сумма «часы × ставка», разбивка по проектам, по дням и по задачам, выгрузка периода в CSV.
- **Импорт из Toggl**: Reports → Detailed → Export → CSV. Повторная загрузка того же файла ничего не дублирует.

## Возможности в стиле Toggl (Tempo)

- **Строка таймера**: `@проект` и `#тег` прямо в названии (с подсказками), теги, флажок «оплачиваемое» ($),
  правка времени старта идущего таймера (клик по «с 09:30»), режим «Вручную» (дата, начало, конец, длительность).
- **Горячие клавиши** (работают и на русской раскладке, не срабатывают в полях ввода): `N` новый таймер,
  `S` стоп, `M` вручную, `C` продолжить последнюю запись, `?` справка. Отключаются в настройках.
- **Три вида**: Список (с боковой панелью «сегодня / неделя» и группировкой похожих записей), Календарь
  (недельная сетка; тяните мышью по пустому месту, чтобы добавить запись; клик по блоку — правка) и Timesheet
  (недельная таблица: вводите время в клетку, Enter; пустая клетка удаляет запись).
- **Отчёты**: Summary (карточки, график по дням, доли проектов, таблицы) и Detailed (каждая запись), фильтры по
  периоду, проекту, тегам, оплате и тексту, выгрузка в CSV.
- **Инвойс за период**: в «Отчётах» кнопка «Инвойс» берёт выбранный период и фильтры. Выберите проект, язык
  (RU/EN), номер (INV-2026-001, нумерация сама растёт), срок оплаты, при необходимости ставку только для этого
  инвойса, уберите или переименуйте позиции. Ваши реквизиты и данные клиента (отдельно для каждого проекта)
  запоминаются в браузере. «Скачать PDF» открывает печать браузера: выберите «Сохранить как PDF», имя файла
  подставится из номера. В инвойс попадает только оплачиваемое время одного проекта; сумма строки = часы
  (2 знака) × ставка, поэтому счёт сходится на калькуляторе.
- **Pomodoro** (25/5/15, настраивается) и **режим фокуса** (во весь экран только таймер). Дневная цель и
  счётчик «3/8», автозапуск следующего помидора после перерыва, мягкий звук вместо резкого сигнала, совет на
  каждый перерыв, число помидоров за период в отчётах.
- **Фоновые звуки** (кнопка с нотой у таймера): дождь, волны, ветер, камин, коричневый и розовый шум. Они
  синтезируются в браузере, без файлов и интернета, их можно смешивать. Играют, пока идёт рабочий интервал (или
  просто идёт таймер), на перерыве — тишина. Пока окно микшера открыто, звук слышно для настройки.
- **Определение простоя**: включается в настройках; работает только в Chrome/Edge и просит разрешение браузера.
  Когда вы вернулись, можно отбросить время простоя, оставить его или начать новый таймер.
- Светлая/тёмная/авто тема. Шрифт Manrope, иконки Hugeicons.

## Онлайн-версия на Vercel

Тот же Tempo можно открывать с любого устройства. Данные хранятся в Upstash Redis. Пароля нет: любой, кто знает
адрес сайта, видит и меняет данные, поэтому адрес никому не давайте. Если пароль понадобится позже, добавьте
переменную `TRACKER_PASSWORD` в Vercel и сделайте Redeploy, появится экран входа.
Локальная версия (`start.bat`) работает как раньше, у неё свой файл данных.

1. Репозиторий уже подключён к Vercel (каждый `push.bat` пересобирает сайт).
2. В проекте на Vercel: **Storage → Marketplace → Upstash Redis → Create**, регион ближе к вам, тариф Free,
   затем **Connect Project** к этому проекту. Переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` появятся сами.
3. **Deployments → ... → Redeploy**. Откройте адрес сайта.
4. Перенос данных: на компьютере в Tempo откройте «Настройки → Данные» и нажмите «Скачать копию данных»
   (или возьмите файл `data\tracker.json`). В онлайн-версии «Настройки → Данные → Загрузить данные из файла»,
   затем «Добавить к текущим». Повторная загрузка того же файла ничего не задвоит.

Без базы онлайн-версия ничего не показывает и пишет, что именно не настроено. Лимит Vercel на
размер запроса — около 4,5 МБ, поэтому очень большой файл копии придётся загружать частями.

## Как считаются деньги

`сумма = время × ставка проекта`. Записи без проекта бесплатны. Если у проектов разные валюты, суммы по
валютам показываются отдельно (они не складываются). Запись, начатая в одном дне и законченная после полуночи,
целиком относится ко дню начала.

## Данные и резервные копии

- Файл: `data/tracker.json`. Перед каждой записью предыдущая версия сохраняется как `data/tracker.json.bak`.
- Если основной файл повредится, трекер прочитает `.bak`; если копии нет — сообщит об ошибке, а не начнёт с пустой базы.
- Для надёжности иногда копируйте папку `data` в облако или на флешку.
- Другой путь к данным: переменная окружения `TRACKER_DATA`; другой порт — `PORT`.

## Разработка

`npm run dev` (сервер + Vite с горячей перезагрузкой), `npm test`, `npm run typecheck`.
Стек: Node + Express (API), React + Vite (интерфейс), данные — JSON-файл.


## Хранилище и копии данных

- **Онлайн (Upstash Redis):** записи хранятся по месяцам (`tempo:v2:e:ГГГГ-ММ`), проекты — отдельно. Запись отправляет только изменённый месяц, поэтому история не упирается в лимит запроса. Старый единый документ (`tempo:state`) читается как есть и не изменяется.
- **Копии:** раз в сутки в 03:00 UTC Vercel Cron вызывает `/api/cron/backup`. Копии (gzip) хранятся в Redis, последние 20. В Настройки → Данные их можно скачать или вернуть; перед возвратом текущие данные сохраняются отдельной копией. Если задан `CRON_SECRET`, вызов принимается только с ним.
- **Локально:** копии лежат в `data/backups/`, суточная создаётся при первом сохранении за день.
- **Удаление записи:** запись исчезает сразу, внизу 6 секунд доступна кнопка «Отменить», потом удаление идёт на сервер.


## Клиенты и счета

- **Клиенты** (Проекты → Клиенты): название, email, адрес, ИНН, валюта и срок оплаты по умолчанию. Проект привязывается к клиенту; у клиента может быть несколько проектов, и все они попадают в один счёт.
- **Счета** (отдельная вкладка): сводка «ждёт оплаты / просрочено / оплачено в этом месяце», фильтры по статусу, просмотр, печать в PDF. Статусы: черновик → отправлен → оплачен. «Просрочен» вычисляется сам: отправлен, а срок прошёл.
- **Новый счёт** собирает позиции из оплачиваемого времени за период. Можно округлить время вверх до 15/30/60 минут, поправить часы и ставку в строке, задать скидку и налог. Записи, уже попавшие в счёт, помечаются и второй раз не выставляются (пока счёт не удалён).
- Счёт хранит копию всех данных (ваши реквизиты, клиент, строки), поэтому правка клиента или записей позже не меняет уже выставленный документ. Ваши реквизиты запоминаются на сервере и подставляются на любом устройстве.
- Номера `INV-ГГГГ-NNN` выдаёт сервер и не повторяет.

## Мобильная версия

Тёмный/светлый интерфейс подстраивается под телефон: нижняя панель вкладок, крупные часы и кнопка старта, мини-таймер на всех экранах кроме самого таймера. Сайт можно установить на экран телефона (кнопка «Установить» / «На экран Домой»); без сети он откроется, но данные требуют соединения.

## Работа без сети

Старт, стоп и добавление времени вручную работают без соединения: действие сразу видно на экране, сохраняется в браузере и уходит на сервер, когда связь вернулась (внизу справа показано, сколько действий ждёт). Сервер получает время нажатия, а не время доставки, и узнаёт повторный запрос по id, поэтому ничего не задваивается. Остальные действия (правка, удаление, счета) без связи показывают ошибку. Если сервер отклонил отложенное действие, оно отбрасывается с сообщением. После выхода из аккаунта очередь и локальная копия данных стираются.

В таймшите работают стрелки (между клетками), Enter (сохранить и вниз) и Esc (отмена правки).
